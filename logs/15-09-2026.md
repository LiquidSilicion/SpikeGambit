## Phase 2: Dataset Generation & Neural Network Training (Completed)

### Objective
Create labeled chess dataset and train neural networks for tactical pattern recognition.

### Dataset Generation
- Generated 5,000 mid-game chess positions using random game simulation
- Implemented heuristic tactical labeling (Check, Hanging Piece, Tactical Threat, Quiet)
- Created 12×8×8 tensor encoding (one-hot per piece type)
- **File:** `ml/dataset/generate_tactical_dataset.py`
- **Output:** `ml/dataset/tactical_dataset.csv`

### Initial SNN Training (Direct Training)
- Implemented Spiking Convolutional Neural Network using SpikingJelly
- Architecture: 2 conv layers (32, 64 filters) + LIF neurons
- **Challenge:** Poor convergence (~58% accuracy) due to:
  - Class imbalance (74% tactical, 15% quiet)
  - Noisy spike encoding (Bernoulli rate coding)
  - Vanishing spike problem in deep networks

### Strategic Pivot: CNN-First Approach
Recognized that direct SNN training was unstable. Pivoted to industry-standard ANN-to-SNN conversion pipeline.

### CNN Training (Phase 1 Baseline)
- **Architecture:** 3 conv layers (32→64→128 filters) + 3 FC layers
- **Enhancements:** BatchNorm, dropout, data augmentation, LR scheduling
- **Training:** 100 epochs with early stopping
- **Final Accuracy:** 81.88% validation accuracy
- **Model Size:** 261,538 parameters

### Key Files
- `ml/training/train_cnn_baseline2.py` - CNN training script
- `ml/training/chess_cnn_enhanced_best.pth` - Best CNN model (81.88%)

## Phase 3: ANN-to-SNN Conversion (Completed)

### Objective
Convert trained CNN to Spiking Neural Network while preserving accuracy.

### Methodology
1. **BatchNorm Folding:** Integrated BN parameters into conv/linear weights
2. **ReLU → LIF Conversion:** Replaced activation functions with Leaky Integrate-and-Fire neurons
3. **Rate Coding:** Simulated network over multiple time steps (T=200)
4. **Threshold Tuning:** Optimized LIF threshold for accuracy retention

### Conversion Results
| Time Steps (T) | SNN Accuracy | Retention |
|----------------|--------------|-----------|
| 10 | 56.50% | 69.86% |
| 50 | 59.00% | 72.95% |
| 100 | 59.12% | 73.11% |
| 200 | 59.50% | 73.57% |
| **200 (threshold=0.5)** | **75.12%** | **92.89%** |

### Best Configuration
- **Time Steps:** T=200
- **LIF Beta (leak):** 0.9
- **LIF Threshold:** 0.5
- **Accuracy:** 75.12% (92.89% retention from CNN)

### Key Files
- `ml/training/convert_to_snn.py` - Conversion script
- `ml/training/chess_snn_best.pth` - Best SNN model

## Phase 4: Quantization & Hardware Implementation (Completed)

### Objective
Quantize SNN weights for FPGA deployment and implement RTL accelerator.

### Weight Quantization
- **Precision:** 8-bit signed integers (int8)
- **Compression:** 4× reduction (1016.88 KB → 254.22 KB)
- **Format:** Verilog-compatible `.mem` files (hexadecimal)
- **Files Generated:**
  - `conv1_weights.mem` (3,456 weights)
  - `conv2_weights.mem` (18,432 weights)
  - `conv3_weights.mem` (73,728 weights)
  - `fc1_weights.mem`, `fc2_weights.mem`, `fc3_weights.mem`
  - Corresponding bias files for all layers

### RTL Implementation

#### 1. LIF Neuron (`hw/rtl/lif_neuron.v`)
- Fixed-point arithmetic (Q8.8 format)
- Leak factor: 0.875 (implemented as right-shift)
- Hard reset after spike firing
- **Verified:** Testbench confirmed correct accumulation, firing, and reset behavior

#### 2. Weight Memory (`hw/rtl/weight_memory.v`)
- Parameterized BRAM storage
- Synchronous read interface
- Loads weights from `.mem` files via `$readmemh`
- Configurable depth and address width per layer

#### 3. Convolution Layer (`hw/rtl/conv_layer.v`)
- 3×3 kernel convolution
- Spike-driven MAC operations (sparse computation)
- Integrated LIF neuron activation
- State machine: IDLE → LOAD_WEIGHTS → COMPUTE → UPDATE_NEURON → CHECK_FIRE

#### 4. Output Classifier (`hw/rtl/output_classifier.v`)
- Spike counting over T=200 time steps
- Argmax decision logic
- Rate coding readout

#### 5. Top-Level Accelerator (`hw/rtl/spikegambit_top.v`)
- Integrates 3 convolution layers (12→32→64→128 channels)
- Progressive spatial pooling (8×8 → 4×4 → 2×2)
- Weight memory instances for each layer
- Output classifier for final prediction

### Verification
- **LIF Neuron Testbench:** ✅ Passed (accumulation, firing, leak verified)
- **Top-Level Testbench:** ✅ Passed (end-to-end inference verified)
- **Compilation:** ✅ Zero warnings after bit-width corrections
